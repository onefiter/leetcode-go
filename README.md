## 整体解题思路

### 数组 / 哈希 / 字符串
- 「找配对、去重、计数」先想哈希表，把 O(n²) 的二重循环降成 O(n)。
- 区间和问题用前缀和，配合哈希表统计「前缀和 - k」出现次数。
- 原地修改数组用读写双指针，字符串题多半是计数数组 / 哈希 + 双指针。

### 双指针 / 滑动窗口 / 二分
- 有序数组找组合：排序 + 左右指针相向收缩，注意跳过重复值。
- 子串 / 子数组满足某条件：右指针扩张、条件违反时左指针收缩，窗口内状态用计数数组维护。
- 二分的关键是找到「单调性」：在答案空间上二分（最小化最大值、第 k 小）也很常见，写之前先想清楚区间开闭和循环终止条件。

### 链表 / 栈 / 队列
- 链表题用哑节点统一头节点处理，快慢指针找中点、判环，反转用三指针迭代。
- 「下一个更大 / 更小元素」「柱状图面积」用单调栈；滑动窗口最值用单调队列。
- 括号匹配、表达式求值用栈模拟。

### 二叉树
- 先判断是「遍历一遍就能求」（前序带状态往下传）还是「需要子树信息」（后序把结果往上返回）。
- 层相关问题用 BFS 按层处理；BST 题利用中序有序。
- 需要往上走的（如距离为 K）先记父指针，把树转成图。

### 回溯
- 统一模板：选择 → 递归 → 撤销；用 `start` 控制组合不回头，用 `used` 控制排列。
- 有重复元素先排序，「同一层跳过相同值」去重。
- 尽早剪枝：剩余元素不够、和已超过目标、棋盘冲突（列 / 对角线标记）。

### 图论
- 依赖关系 / 判环用拓扑排序（Kahn 入度 BFS 或 DFS 三色标记）。
- 连通性、合并、冗余边用并查集（`template.UnionFind`）。
- 最短路：无权图 BFS，非负权 Dijkstra + 堆，限制边数用 Bellman-Ford 按轮松弛。
- 二分图用 BFS / DFS 染色。

### BFS（网格 / 状态搜索）
- 求最短步数一律 BFS，按层扩展；多个起点同时入队即多源 BFS（腐烂橘子、01 矩阵）。
- 状态不止坐标时把额外维度并进 visited（如剩余可消除障碍数）。
- 起点和终点都已知时可用双向 BFS 大幅减少搜索量（单词接龙、转盘锁）。

### 动态规划
- 四步走：定义状态 → 写转移方程 → 确定初始值 → 确定遍历顺序，最后再考虑滚动数组压缩空间。
- 线性 DP：`dp[i]` 表示以 i 结尾 / 前 i 个的最优值（打家劫舍、最长递增子序列、股票状态机）。
- 背包：01 背包容量倒序遍历，完全背包正序遍历；求组合数物品在外层，求排列数容量在外层。
- 区间 DP：`dp[i][j]` 由更短区间推出，按长度递增或 i 倒序遍历（戳气球、回文子序列）。
- 双串 DP：`dp[i][j]` 表示两串前缀的关系（编辑距离、LCS、正则 / 通配符匹配）。

### 贪心
- 每一步取局部最优，并能用「交换论证」说明不会更差。
- 区间题先排序：选最多不重叠区间按右端点排序，会议室数量按起止时间扫描。
- 跳跃类维护「当前能到的最远位置」；分糖果这类双向约束左右各扫一遍。

### 堆 / 字典树 / 设计题
- Top K、第 K 大用堆或快速选择；数据流中位数用大小两个堆。
- 前缀匹配、多单词搜索用 Trie，搜索时边走边剪枝。
- 设计题先确定每个操作的目标复杂度，再组合数据结构：哈希表 + 双向链表（LRU、全 O(1)）、切片 + 哈希表（O(1) 随机删除）。
